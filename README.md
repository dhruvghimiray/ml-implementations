# Machine Learning

A collection of notebooks exploring machine learning algorithms, concepts, and practical applications. The aim is to understand how different models work, how to implement them using Python, and how to evaluate their performance.

## Repository Structure

```text
machine-learning/
│
├── notebooks/
│   ├── classification/
│   ├── regression/
│   └── clustering/
│
├── results/
│
└── README.md
```

## Topics Covered

### 1. Classification
Notebooks covering classification algorithms and their applications.

Topics may include:
- Logistic Regression
- K-Nearest Neighbours (KNN)
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)
- Naive Bayes
- Model evaluation and classification metrics

### 2. Regression
Notebooks exploring regression techniques for predicting continuous values.

Topics may include:
- Simple and Multiple Linear Regression
- Polynomial Regression
- Ridge and Lasso Regression
- Decision Tree Regression
- Random Forest Regression
- Gradient Boosting
- Model evaluation and regression metrics

### 3. Clustering
Notebooks focused on unsupervised learning and finding patterns in data.

Topics may include:
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Dimensionality Reduction
- Clustering evaluation techniques

## Results

The `results/` directory stores outputs generated during experiments, such as:
- Model evaluation metrics
- Prediction results
- Visualisations
- Other experiment outputs

## Tools and Libraries

The notebooks primarily use Python and its data science ecosystem:

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Purpose

This repository serves as a practical learning space for studying machine learning. Each notebook is intended to document the process, from exploring a dataset and understanding the problem to training models and evaluating their results.

The notebooks and experiments will be added and updated as I work through different algorithms and techniques.
